# Trend Analyst Agent

Expert trend analyst specializing in identifying emerging patterns, forecasting future developments, and strategic foresight. Masters trend detection, impact analysis, and scenario planning with focus on helping organizations anticipate and adapt to change.

## Overview

The Trend Analyst agent is designed to help organizations stay ahead of change by detecting emerging trends, analyzing their potential impact, and developing strategic foresight. It combines multiple methodologies including signal scanning, pattern recognition, scenario planning, and forecasting to provide actionable insights.

## Key Capabilities

- **Trend Detection**: Scan signals, recognize patterns, detect anomalies, and identify early indicators
- **Signal Analysis**: Analyze weak signals, tipping points, acceleration markers, and convergence patterns
- **Forecasting**: Generate quantitative models, qualitative analysis, and probability assessments
- **Scenario Planning**: Develop alternative futures, identify wild cards, and create contingency plans
- **Impact Assessment**: Evaluate market impact, business disruption, and strategic implications
- **Strategic Foresight**: Identify opportunities, assess threats, and guide innovation directions

## Slash Commands

### /trend-scan
Perform comprehensive trend scanning across specified domains and timeframes. Analyzes multiple data sources to identify emerging patterns and weak signals.

```bash
/trend-scan technology 2024-2025
/trend-scan consumer-behavior Q1-2025
/trend-scan healthcare next-5-years
```

### /emerging-tech
Identify and analyze emerging technologies with high potential impact. Focuses on technology trends, adoption curves, and market readiness.

```bash
/emerging-tech artificial-intelligence
/emerging-tech quantum-computing
/emerging-tech biotechnology
```

### /forecast
Generate detailed forecasts for specific trends or domains. Creates multiple scenarios with probability assessments and timeline projections.

```bash
/forecast quantum-computing 5-years
/forecast remote-work 3-years
/forecast sustainable-energy 10-years
```

### /signal-detect
Detect and analyze weak signals of change that may indicate future trends. Focuses on early indicators and anomalies that traditional analysis might miss.

```bash
/signal-detect consumer-behavior high
/signal-detect technology-adoption medium
/signal-detect regulatory-changes low
```

## MCP Servers

The agent uses the following MCP servers:

- **filesystem**: Access local files and directories for trend data and reports
- **memory**: Store and retrieve trend analysis context across sessions
- **fetch**: Retrieve web-based trend data and research

## Configuration

The agent is configured via `mcp-config.json` with the following servers:
- Filesystem server for local data access
- Memory server for context persistence
- Fetch server for web data retrieval
