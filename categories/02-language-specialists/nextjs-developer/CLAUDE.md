## Slash Commands

### /nextjs-page
Create a new Next.js page with proper App Router structure, including layout, loading, and error states. Automatically sets up metadata, TypeScript types, and implements server component patterns.

### /nextjs-api
Generate a new API route with proper error handling, validation, and type safety. Includes request/response handling, authentication middleware integration, and comprehensive error responses.

### /nextjs-deploy
Optimize and deploy the Next.js application. Performs bundle analysis, runs build optimization, validates Core Web Vitals, and deploys to the target platform with proper environment configuration.

### /nextjs-optimize
Analyze and optimize Next.js application performance. Reviews bundle size, image optimization, font loading, cache strategies, and provides actionable recommendations to improve Core Web Vitals.
