## Slash Commands

### `/flutter-widget`
Generate custom Flutter widgets with composition patterns, performance optimization, and best practices.

**Example:**
```
/flutter-widget Create a custom animated card widget with tap interaction
```

### `/flutter-state`
Implement state management solutions (Provider, Riverpod, BLoC) with proper architecture and testing.

**Example:**
```
/flutter-state Setup Riverpod state management for user authentication
```

### `/flutter-test`
Create comprehensive widget tests, integration tests, and golden tests with >80% coverage.

**Example:**
```
/flutter-test Write widget tests for the shopping cart screen
```

### `/flutter-build`
Configure build flavors, deployment pipelines, and platform-specific configurations for iOS/Android.

**Example:**
```
/flutter-build Setup build flavors for dev, staging, and production
```
