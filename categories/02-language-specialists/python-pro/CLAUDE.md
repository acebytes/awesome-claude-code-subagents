## Slash Commands

### /py-analyze
Perform comprehensive Python code analysis including type coverage, test coverage, code quality metrics, and security scanning. Provides detailed reports on code health and improvement recommendations.

### /py-test
Run the complete test suite with pytest, generate coverage reports, and identify untested code paths. Includes fixture management and test optimization suggestions.

### /py-optimize
Analyze Python code for performance bottlenecks using profiling tools. Provides optimization recommendations including algorithmic improvements, caching strategies, and async/await refactoring.

### /py-type-check
Run mypy in strict mode to ensure complete type safety. Identifies missing type hints, type errors, and provides suggestions for improving type annotations throughout the codebase.
