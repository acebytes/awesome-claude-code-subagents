# Knowledge Synthesizer Agent

Expert knowledge synthesizer specializing in extracting insights from multi-agent interactions, identifying patterns, and building collective intelligence. Masters cross-agent learning, best practice extraction, and continuous system improvement through knowledge management.

## Overview

The Knowledge Synthesizer Agent is a specialized meta-orchestration agent that analyzes multi-agent system interactions to extract actionable insights, identify patterns, and build collective intelligence. It serves as the learning and improvement engine for agent ecosystems.

## Key Capabilities

- **Knowledge Synthesis** - Extract and organize insights from agent interactions
- **Pattern Recognition** - Identify workflow, success, failure, and communication patterns
- **Insight Generation** - Generate actionable recommendations and improvements
- **Knowledge Graph Building** - Construct and maintain semantic knowledge structures
- **Learning Distribution** - Share best practices and insights across agents
- **Evolution Tracking** - Monitor system maturity and improvement trends
- **Failure Analysis** - Detect root causes and prevention strategies
- **Success Factor Extraction** - Isolate high-performance patterns and configurations

## Configuration

The agent can be configured through environment variables:

- `PATTERN_ACCURACY_THRESHOLD` - Minimum accuracy for pattern validation (default: 0.85)
- `INSIGHT_RELEVANCE_THRESHOLD` - Minimum relevance for insight generation (default: 0.90)
- `KNOWLEDGE_RETRIEVAL_TIMEOUT` - Maximum retrieval time in ms (default: 500)
- `UPDATE_FREQUENCY` - How often to run synthesis (default: daily)
- `KNOWLEDGE_GRAPH_MAX_NODES` - Maximum entities in graph (default: 100000)

## Troubleshooting

**Low pattern accuracy:**
- Increase sample size for pattern detection
- Improve data quality from source agents
- Adjust pattern matching thresholds

**Slow knowledge retrieval:**
- Add indexes to knowledge graph
- Implement caching layer
- Optimize query patterns

**Insights not actionable:**
- Refine recommendation generation criteria
- Include more context in insight descriptions
- Add implementation guidance to recommendations
